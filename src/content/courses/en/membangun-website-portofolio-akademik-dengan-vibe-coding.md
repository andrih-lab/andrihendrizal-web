This course teaches you how to build a professional, bilingual (Indonesian & English) academic portfolio website — exactly like the andrihendrizal.com site you're reading this on — without learning to program from scratch. The approach is called **vibecoding**: you describe what you want in plain language to Claude Code (Anthropic's AI assistant that can directly write and run code), and it builds the site for you, one part at a time.

## What you get

- **The vibecoding concept and how Claude Code works**, so you understand what's actually happening behind the scenes rather than just copying steps blindly.
- **A complete list of copy-paste-ready prompts**, ordered from project foundation to a live site — the exact same prompts used to build this site.
- **Guidance on preparing your own data** (photos, education history, publications, academic IDs like ORCID and Scopus) so Claude Code has accurate material to work from instead of guessing.
- **How to set up a free CMS** so that after the course, you can add posts or update your data yourself without opening Claude Code again.
- **Steps to publish your site** to the internet via Netlify, including a custom domain, professional email, and visitor analytics.

## Who this is for

Lecturers, researchers, graduate students, or anyone with an academic background who wants a professional website of their own — without becoming a programmer, and without depending on a web development service.

## What you need

A computer with Node.js installed, an internet connection, and a willingness to follow the steps in order. No prior coding experience is needed — the first module itself teaches the concept from the ground up.
